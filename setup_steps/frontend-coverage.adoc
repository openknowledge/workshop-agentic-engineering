= Code Coverage Konfiguration

Die Gesamtabdeckung wird aus Playwright-E2E-Tests und Vitest-Komponententests kombiniert.
Beide Testreihen werden über dasselbe Vite-Plugin (`vite-plugin-istanbul`) instrumentiert,
damit ihre Coverage-Snapshots dieselben Statement- und Branch-Maps verwenden und sauber zusammengeführt werden können.
**NYC** führt die Ergebnisse zusammen und prüft die Schwellenwerte.

== Installation

[source,bash]
----
npm install --save-dev vite-plugin-istanbul nyc
----

=== Package.json

[source,json]
----
"nyc": "^18.0.0",
"vite-plugin-istanbul": "^9.0.0"
----

== Ablauf

[source]
----
1. coverage:clean          → .nyc_output/ leeren
2. test:unit:coverage      → Vitest läuft mit VITE_COVERAGE=true; setup.ts schreibt
                              window.__coverage__ als vitest-<uuid>.json nach .nyc_output/
3. test:e2e:coverage       → Playwright startet einen instrumentierten Dev-Server und
                              schreibt pro Test einen playwright-<uuid>.json nach .nyc_output/
4. test:coverage:report    → NYC führt alle Snapshots zusammen und erstellt den Report
                              in coverage/combined/
----

Da beide Quellen über dieselbe `vite-plugin-istanbul`-Instrumentierung laufen,
sind ihre Statement- und Branch-Maps kompatibel und NYC kann die Counts ohne Map-Konflikte addieren.

Nach `test:coverage` schlägt der Build fehl, wenn ein Schwellenwert unterschritten wird (`check-coverage: true` in `.nycrc.json`).
